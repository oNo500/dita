## 一、用户提出的新政策

来源节的形态：

```
来源
DITA-OT 官方文档 https://xxxx
上边描述引用了这个来源
```

四条主张：

1. **来源＝一句话＋地址**，不做「事实/判断」两段划分
2. **自造内容与判断不必标注**——它本来就是自造的
3. **位置灵活**：每段开头或结尾，不必是底部专节
4. **不必每篇都有**，可以一个来源都没有

外加一条方向相反的约束：**自造内容谨慎引入，怕被污染，当前阶段以专业为主。**

## 二、准入判据（用户 2026-08-19 补充）

> 先问业界有没有对应的体系分类。有就用它。没有的话，靠多个类比三角定位，并标为「比较」——除非价值特别大，否则根本不该成篇。

核心：**单一自造的断言不可证伪，多方对照的比较可核。** 无上游时不许直陈，只许并列对照。

## 四、最深的一处后果：腐烂检测缺一角

四套腐烂检测里第一套「一条事实过期」锚在**来源页面**上（`reviewed` 日期 + `volatility` + 来源链接），构成"上游改了我能发现"的闭环。

**纯自造内容没有这个锚。** 它不会因上游改版而过期，但会因**我们自己的判断被推翻**而过期，而那没有任何机制能检测。

所以"允许零来源"不只是放松一条校验，是让一部分内容**退出腐烂检测的覆盖范围**。

## 五、关键区分：放松一件、收紧另一件

- **标注形式** → 放松（两段划分、穷尽归属、每篇必有，都是仪式）
- **内容准入** → 收紧（自造谨慎引入、以专业为主）

**现行系统把这两件混在了一起**：穷尽归属那套仪式实际承担的是准入纪律——逼作者把每条无出处的话显式列出，列的时候自己会心虚。取消仪式，纪律就悬空，除非换个东西接住。

这正是用户担心的"被污染"：**没有标注负担之后，自造内容进来的阻力就没了。**

## 六、库内实测（2026-08-19，124 篇）

- 声明 `upstream-node="coined"` 的 dita 篇：**26**
- content-engineering（本库方法论）：**13**
- 来源节事实段为「无」的：`naming-rules`、`rot-detection`、`writing-style`

三篇实测：

- **`writing-principles-landscape` 通过**——无单一上游，但做了五路对标（Diátaxis / Good Docs / 微软 / 谷歌 / ISO 704），已是比较形态，只是没自称比较
- **`rot-detection` 卡住**——把四套机制归为一个模式，纯自造归纳、无类比支撑。而它有现成的业界类比可对：link rot 检测、依赖新鲜度（dependabot 一类）、schema 版本兼容、缓存失效。对标后它从"我发明了一个模式"变成"这个模式在几个领域都成立，本库是第四个实例"，可信度完全不同
- **`writing-style` / `naming-rules` 属边界情况**——本库自订规章，不需要业界背书

## 七、术语冲突：两个「自造」

- **R19 的 `coined`** 指「上游没有这个**节点名**」——管标题溯源
- **本政策的「自造」** 指「内容无外部来源」——管断言可信度

26 篇声明 `coined` 的 topic 里，多数正文事实是有出处的。**两件事必须分开命名**，否则规则会互相误读。

## 八、用户裁定（2026-08-19，交互确认）

| # | 项 | 裁定 |
|---|---|---|
| 1 | **R8 走向** | **改判据：必须显式声明来源状况**。有来源就列；无来源写一句「本篇无外部来源，属本库方法论」。仪式降到一句话，但「这篇没来源」仍显式——机器查得到、读者看得见、作者写下时仍有心理成本 |
| 2 | **事实/判断两段与穷尽归属** | **都废**。来源节只列有来源的那些，其余默认为本库判断。R14 相应改写 |
| 3 | **无来源篇的成熟度上限** | **封顶 curated，不得晋 verified**。verified 的现行定义就是「完成来源逐条核对」，无来源天然对不上 |
| 4 | **「比较」形态** | **新增 comparison 体裁**，带必需节（对照对象 / 各方做法 / 差异 / 本库取舍）。机器可校验结构，与既有八个体裁同级 |

## 九、落地影响面（据裁定推算，执行前再核）

- **R8**：assert 由「必须有 source 或外链」改为「必须有来源节且其内容非空」——注意不能退化成「有文字即可」，需想清可判定的形式
- **R14**：删两标签断言，改为形式约束（一句话＋地址，或声明句）。**全库 90 篇来源节要改**——上一轮刚做的条目式仍可用，只是判断段整体删除
- **母版通则**：删「两段须穷尽正文全部断言的归属」一条；`writing-sourcing` 与迁移计划的 Global Constraints 同步
- **成熟度**：新增校验「无来源不得 verified」（现全库 0 篇 verified，眼下零命中，属前置防护）
- **comparison 体裁**：`genre-values` 加值 + `required-section` + `dita-type`；R12/R13 自动生效；`rot-detection` 按新判据须补业界类比或改挂 comparison
- **术语**：`coined`（R19，指上游无此节点名）与「自造」（内容无外部来源）**必须分开命名**，否则规则互相误读
